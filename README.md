# Student Assignment Tracker

**Name:** Uyioghosa Uzamere

## Project Description
The Student Assignment Tracker is a Python program that helps students organize their assignments and keep track of due dates. Users can add assignments, view their assignments, and mark assignments as completed.

The program will save assignment information using CSV files so students can access their assignments later.

## Technologies
- Python
- GitHub
- CSV files
- IDLE (Python editor)
